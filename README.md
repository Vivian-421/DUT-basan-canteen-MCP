# 八三食堂 MCP

让你的 AI 陪你决定今天吃什么，也能记住你对每道菜的评价。

这是一个面向大连理工大学盘锦校区同学的八三食堂菜单 MCP，主要为使用个性化 AI 陪伴聊天服务的同学设计。把它接到自己已有的 AI 里，就可以在聊天中查询菜单、挑选想吃的菜，保存自己的口味偏好和简短备注。任何人都可以使用，不需要验证校友身份。

**开始使用：[八三食堂连接页](https://chat.vivianchat.com/canteen)**

## 能做什么

- **查菜单**：查看分类、菜名、价格、采集时月售，以及已经收录的口味和加料信息。
- **挑选菜品**：按关键词、分类、主菜价格和个人偏好筛选，支持按价格排序。
- **记录偏好**：给菜品标记“未评价”“没吃过”“不喜欢”“一般”“喜欢”“很喜欢”。
- **保存备注**：记录值得以后选餐参考的评价，例如“有点咸”“这次肉比较柴”，每道菜最多 200 字。
- **跨聊天使用**：记录保存在食堂档案中，换聊天后仍可以查询；在不同客户端使用同一邮箱建立的连接，也能使用同一份记录。

例如，你可以对自己的 AI 说：

> 今晚想吃面，看看八三有哪些选择，尽量控制在二十元以内。
>
> 这道菜我很喜欢，帮我记下来。
>
> 上次吃这个觉得有点咸，下次选餐时提醒我。

MCP 提供查询和保存工具；AI 是否主动调用、何时调用，仍取决于你使用的客户端、模型和角色设置。

## 个人档案

每个人的偏好和备注分别保存，首次使用时从空白开始。公开连接不会带入项目作者的个人评价。

使用邮箱验证码即可建立独立的食堂档案，不需要注册 VivianChat，也不需要设置密码。在另一台设备或另一个客户端上验证同一邮箱后，可以继续使用原来的记录。

你可以在连接页撤销全部客户端连接凭据，已保存的偏好和备注会保留。凭据遗失后，也可以重新验证邮箱并生成新的连接。

## 接入 DSH

1. 打开[连接页](https://chat.vivianchat.com/canteen)，填写常用邮箱并获取验证码。
2. 验证邮箱后，为自己的客户端生成一个个人连接。
3. 复制页面生成的配置，合并到你实际使用的 DSH profile 的插件列表中，保留已有插件和角色设置。
4. 启动或重新加载配置，确认八三的四个工具已经启用，然后在聊天中尝试查询菜单。

配置格式如下。请使用连接页生成的真实凭据替换占位内容：

```yaml
- id: basan-menu
  name: '@deepseek-ai/dsh-mcp-client'
  config:
    serverName: basan
    transport: streamable-http
    url: https://chat.vivianchat.com/mcp/canteen-public
    headers:
      Authorization: 'Bearer 你的个人连接凭据'
```

这是一条插件配置，需要合并到已有配置中，不要用它覆盖整个 profile。DSH 需要能够加载 `@deepseek-ai/dsh-mcp-client`；不同版本的安装和配置入口，以对应版本的说明为准。

## 接入已有的 QQ AI

如果你的 QQ AI 基于 DSH，并使用 `dsh-qqbot`，将上面的八三插件加入 **QQ 机器人正在使用的同一个 DSH profile**，再确认该 QQ 角色也能使用八三工具。

不需要重新注册 QQ 机器人，也不需要替换现有角色。接入之后，仍然与原来的 AI 聊天，由它按需调用菜单工具。

**一个个人连接对应一个人的食堂档案，不会按 QQ 发言人自动切换。** 请只把自己的连接用于自己使用的 AI，不要将这份配置用于多人共用、要求每人分别保存偏好的公共机器人。不要把真实连接凭据放进公开配置、Issue 或截图中。

## 提供的工具

| 工具 | 用途 |
| --- | --- |
| `get_canteen_menu` | 查看分类总览，或读取指定分类的菜单 |
| `search_canteen_dishes` | 按关键词、分类、价格和个人偏好查找菜品 |
| `set_canteen_dish_preference` | 保存或修改某道菜的个人偏好 |
| `set_canteen_dish_note` | 保存、修改或清除某道菜的简短备注 |

修改偏好会保留已有备注，修改备注也会保留已有偏好。同一道菜在不同分类中展示时，共用该人的评价。

## 菜单信息

菜单来自微信小程序“八食堂三楼丨大洼店”的保存快照，查询结果会注明采集时间。

- 价格和月售以采集时的信息为准，当前并非实时同步。
- 标注“起”的价格不表示所有规格都符合预算；加料另计价。
- 不保存或展示临时售罄、剩余份数。
- 未收录的规格、份量和配料不会自动补全。
- 目前不支持创建订单或付款，请以商家实际菜单和结算信息为准。

## 反馈
